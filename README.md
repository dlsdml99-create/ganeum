## 소개

**계산기**
- 결과 아래에 `4만 3,700원`처럼 한글 단위와 `≈ 32.66 USD` 같은 환율이 자동으로 나와요
- 식 속 숫자를 누르면 그 숫자만 고칠 수 있어요. 계산이 끝난 뒤에도 위의 식을 누르면 다시 고쳐요
- 괄호 ( ) 키, 계산 기록, 결과 누르면 복사

**프리셋 (자주 쓰는 계산식)**
- 부가세 포함·빼기, 할인, N빵, 평→㎡ 칩을 누르면 바로 계산
- 같은 계산을 3번 하면 칩으로 자동 등록 (예: `×1.1+3,000`)
- `가격 × 1.1 + 배송비`처럼 이름을 넣어 식을 쓰면 입력칸이 저절로 생겨요
- 묶음 5가지를 한 번에: 여행(화씨·마일·파운드), 쇼핑(개당 가격·추가 할인), 부동산(보증금↔월세), 금융(대출 월 상환·적금 만기), 직장인(시급↔월급)
- 내가 만든 식을 카톡으로 공유하면 받은 사람이 눌러서 바로 넣어요

**환율**
- 49개 통화, 아무 통화나 눌러 금액을 넣으면 나머지가 바로 바뀌어요
- 하루 한 번 자동 업데이트, 인터넷이 없으면 저장된 환율로 계산

**안심하고 쓰세요**
- 권한은 인터넷 하나뿐이에요 (환율 받기·새 버전 확인)
- 계산 기록과 프리셋은 폰에만 저장되고 어디로도 보내지 않아요
- 새 버전이 나오면 앱을 열 때 알려 줘요
