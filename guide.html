계산기자주 쓰는 계산묶음공유환율업데이트

계산기

숫자를 넣으면 원화와 환율이 같이 보여요결과 아래에 "4만 3,700원" 같은 한글 단위와 "≈ 32.66 USD" 같은 환율이 자동으로 나와요. 환율 칸을 누르면 어느 돈으로 바꿔 볼지 고를 수 있어요.
틀린 숫자만 고치기입력 중인 식에서 숫자를 누르면 초록색으로 골라져요. 새로 치면 그 숫자만 바뀌어요. 계산이 끝난 뒤에는 결과 위의 식(고치기)을 누르면 다시 불러와요.
아주 큰 수도 정확하게16자리가 넘는 곱셈·덧셈도 끝자리까지 정확하게 보여 줘요. 예) 99,999,999×99,999,999 = 9,999,999,800,000,001
괄호 ( ) 키칩 줄 오른쪽 ( ) 키를 누르면 괄호가 열리고, 숫자 뒤에서 한 번 더 누르면 닫혀요.
복사·기록결과 숫자를 누르면 복사돼요. 위쪽 기록을 누르면 그 결과를 다시 써요. ⌫를 길게 누르면 모두 지워요.

자주 쓰는 계산 (계산식)

칩 한 번으로 계산숫자를 넣고 키패드 위의 칩(부가세 포함, 할인 30%, N빵 ÷4 등)을 누르면 바로 계산돼요. 할인율·인원은 알림의 "값 바꾸기"로 고쳐요.
자동 칩같은 계산(예: ×1.1+3,000)을 3번 하면 동전 모양 칩으로 저절로 올라와요. 자주 쓰는 계산 탭에서 "저장"을 누르면 계속 남아요.
기록을 길게 눌러 계산식으로계산기 위쪽 기록에서 한 줄을 길게 누르면 그 계산이 새 계산식으로 열려요. 앞 숫자는 □(그때 넣는 숫자)로 바뀌어서, 저장하면 다른 숫자에도 칩 한 번으로 쓸 수 있어요.
내 계산식 만들기자주 쓰는 계산 탭 → 새 계산식 → "가격 × 1.1 + 배송비"처럼 이름을 넣어 쓰면 입력칸이 생겨요. 배송비를 미리 채워 두면 칩 한 번으로 끝나요. ★를 켜면 계산기 칩에 나와요.

계산식 묶음

묶음째 한 번에 넣기자주 쓰는 계산 탭 → 계산식 묶음에서 여행(화씨·마일·파운드), 쇼핑(개당 가격·추가 할인), 부동산(보증금↔월세), 금융(대출 월 상환액·적금 만기), 직장인(시급↔월급)을 골라 "모두 넣기"를 누르세요.

계산식 공유

보내기계산식 옆 공유 버튼 → 카톡을 고르면 링크가 담긴 메시지가 가요.
받기받은 링크를 누르고 "가늠 앱에 넣기"를 누르면 바로 들어가요. 또는 메시지를 길게 눌러 공유 → 가늠을 골라도 돼요.

환율

통화 하나만 넣으면 나머지는 자동환율 탭에서 통화를 누르고 금액을 넣으면 다른 통화가 바로 바뀌어요. + 버튼으로 49개 통화 중에서 더하거나 뺄 수 있어요.
자동 업데이트환율은 하루 한 번 저절로 새로 받아요. 인터넷이 없으면 마지막에 받은 환율로 계산해요. 은행에서 바꿀 때는 수수료만큼 차이가 나요.
결과 복사위쪽 복사 버튼을 누르면 "100 USD = 133,804원 = 15,788 JPY"처럼 바꾼 금액이 한 번에 복사돼요. 카톡에 붙여 넣으면 끝.
환율에서도 N빵·할인환율 탭에서도 키패드 위 칩(N빵 ÷4, 할인 30% 등)을 누르면 모든 통화가 한 번에 나눠지거나 깎여요. 예) 120,000엔 → N빵 ÷4 → 한 사람 30,000엔 = 약 25만 원.

업데이트·버전

버전 확인왼쪽 아래 v1.4 같은 숫자가 지금 버전이에요. 누르면 업데이트 내용이 보여요. 새 버전이 나오면 버전 글자가 노란색으로 바뀌어요.
새 버전 받기새 버전이 나오면 앱을 열 때 알려 줘요. "업데이트"를 누르고 받은 파일을 설치하면 기록과 계산식은 그대로 남아요.
백업 (폰 바꿀 때)왼쪽 아래 버전을 누르고 "백업 파일로 저장" → 새 폰에서 "백업 불러오기"로 그 파일을 고르면 기록·계산식·통화 목록이 그대로 돌아와요. 저장할 때 비밀번호(8글자 이상)를 넣으면 그 비밀번호로 잠가요. 잊으면 열 수 없으니 꼭 기억해 두세요.
